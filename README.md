## Swift Playground Snake Game

This repository now includes a standalone Swift Playground snake game in `SnakePlayground.swift`.

### How to run

1. Open **Swift Playgrounds** (iPad or macOS).
2. Create a new blank playground.
3. Paste the contents of `SnakePlayground.swift` into the playground.
4. Run the playground live view.

### Controls

- Use the on-screen arrow buttons to steer.
- Eat red food to grow and increase your score.
- Avoid walls and your own body.
- Tap the board (or press **Restart**) after game over.
